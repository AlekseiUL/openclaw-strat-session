## 🎯 Что это?

AI-скилл, который проводит стратегическую сессию как профессиональный бизнес-коуч:

- 📋 **Онбординг** - изучает ваш бизнес через серию вопросов
- 📊 **Scorecard** - отслеживает ключевые метрики с трендами
- 🪨 **Rocks** - квартальные приоритеты (EOS)
- 🎯 **ONE WIG** - один главный приоритет (4DX)
- 💀 **Pre-mortem** - заранее находит слабые места плана
- ❓ **5 Whys** - докапывается до корневых причин проблем
- 📈 **Lead Measures** - фокус на действиях, не результатах
- 🧠 **Когнитивные ловушки** - следит за 7 типичными ошибками мышления
- 🛑 **Stop Doing** - помогает отказаться от лишнего

## 👤 Для кого?

- Соло-предприниматели и фрилансеры
- Контент-криейторы
- Стартапы и малый бизнес
- Команды до 50 человек

Скилл адаптируется: при первом запуске определяет, работаете вы один или с командой.

## 🚀 Быстрый старт

### Установка

```bash
# Скопируйте SKILL.md в папку скиллов вашего агента
cd ~/your-workspace/skills
mkdir strat-session
cp /path/to/SKILL.md strat-session/SKILL.md
```

### Использование

Скажите агенту:
- "Давай проведём стратсессию"
- "Стратегическая сессия"
- "Итоги месяца"
- "Цели на следующий месяц"

При первом запуске скилл проведёт онбординг (5-10 минут), чтобы узнать ваш бизнес.

## 💾 Куда сохраняет результаты?

Скилл спросит, где вы ведёте записи, и адаптируется:

- **Obsidian** - .md файлы в ваш vault
- **Notion** - готовый markdown для копирования
- **Google Docs** - если настроена интеграция
- **Файлы** - `memory/strat-sessions/` (по умолчанию)

## 🧠 Когнитивные ловушки

Скилл отслеживает 7 типичных ошибок при планировании:

1. **Planning Fallacy** - переоценка возможностей
2. **Sunk Cost** - "уже вложил, надо продолжать"
3. **Confirmation Bias** - видеть только хорошее
4. **Status Quo** - "и так нормально"
5. **Shiny Object** - бросать текущее ради нового
6. **Perfectionism** - не выпускать пока не идеально
7. **Comparison** - сравнивать себя с теми, кто на другом этапе
